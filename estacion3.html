Control de presión

El modelo se vuelve inestable cerca de un valor prohibido.

Modelo racional

\[ h(x)=\frac{-6}{x-3}+1 \]

Obtener el código

El código se forma con:

  • raíz;
  • asíntota vertical;
  • asíntota horizontal;
  • ordenada al origen.
En \(\frac{k}{x-a}+b\), las asíntotas son \(x=a\) e \(y=b\). Para la raíz, igualen toda la expresión a cero.
