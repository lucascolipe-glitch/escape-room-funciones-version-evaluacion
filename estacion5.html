Escala de diagnóstico

El último módulo solo admite entradas mayores que un valor límite.

Modelo logarítmico

\[ q(x)=\log_2(x-4) \]

Obtener el código

El código se forma con:

  • asíntota vertical;
  • raíz;
  • base del logaritmo;
  • 0, porque no existe ordenada al origen.
El argumento debe ser positivo: \(x-4>0\). Para la raíz, usen que \(\log_2(1)=0\).
