Respuesta del alternador

La señal aumenta rápidamente a partir de un nivel de referencia.

Modelo exponencial

\[ p(x)=3^x-9 \]

Obtener el código

El código se forma con:

  • dos cifras para la raíz;
  • dos cifras para el valor absoluto de la asíntota horizontal.
Para la raíz: \(3^x-9=0\). Recuerden que \(9=3^2\).
